Plusauri builds [Tutilis](https://plusauri.com), a desktop application for modeling a household's financial plan. The plan stays on your computer. You buy the app once, when sales open.

The [Learning Center](https://plusauri.com/learn) is the public introduction: case studies, each worked on a live plan beside the writing. No install is required there.

This organization is where Plusauri publishes work it chooses to share.
